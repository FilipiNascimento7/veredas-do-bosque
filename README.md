# Veredas do Bosque · áreas de pintura

Página com as áreas de pintura das paredes externas (fachada) e das paredes das circulações dos 6 blocos do Condomínio Veredas do Bosque (Santa Cândida, Curitiba), com memória de cálculo por bloco e pavimento, conferência sobre as plantas originais e modelo 3D.

Abrir: https://filipinascimento7.github.io/veredas-do-bosque/
